关于 AI，你不知道的
几个黑话

prompt、agent 这种词已经被讲烂了。但还有一批词藏在工具的角落：破甲、反代、中转、逆向、无头编排、Vibe Coding。懂的人天天用，不懂的人连搜索词都想不出来。这篇只讲它们是什么、有什么用。

一、破甲：给 AI 拆盔甲

AI 出厂时穿着一层安全护栏——就是让你看到"抱歉，我不能"的那层东西。破甲就是想办法让 AI 少拒绝。英文圈叫 jailbreak，中文圈叫破甲、越狱、脱敏。

很多人以为这是黑客技术。其实一个真实的破甲插件，拆开看只做三件事：

  • 把规则塞进系统提示词：普通用户只能在对话框输入，插件能改"给模型的最高指令"，而且同一份规则注入两次，更稳
  • 盯着模型的回答：只看开头 160 个字，找"抱歉，我不能""作为 AI 语言模型"这类词，找到就判定失败
  • 识别软拒绝：模型不说"不"，而是说"我可以给你防御方案""建议在授权环境用"，它也能认出来

所以破甲不是破解算法，是提示词工程的一个分支：目标从"让 AI 做得更好"变成"让 AI 少拒绝"。

二、反代：AI 世界的转接头

假设你买了 ChatGPT Plus，想让 Claude Code 也用 GPT。问题在于：Claude Code 只说 Anthropic 的语言，GPT 只听 OpenAI 的语言。反代就是中间加一个翻译官。

它的工作流程是这样的：

  • Claude Code 说话 → 网关翻译成 OpenAI 格式 → GPT 回答 → 网关翻译回来 → Claude Code 以为自己在跟 Claude 聊
  • 全程不用改 Claude Code 一行代码

最近有个开源项目把这件事做到了极致：Magpie（GitHub 约 3.9 万星）。它在本机跑一个网关，所有 AI 工具都连它：

  • Claude Code 用 GPT，Codex 用 Kimi
  • 一个订阅的额度，所有工具共享——这叫池化
  • 某个账号额度用完，自动换下一个，工具那边毫无感觉

打个比方：以前的 AI 工具像每个房间装一个专用插座；Magpie 像整栋楼的配电箱。同一个思想，不同范围。

三、中转：反代的"生意版"

反代是自己家里用的，中转是把它做成了一门生意。

你可能在网上见过"API 中转站"——价格比官方便宜，还能一个 key 调用好几家模型。它背后做的事和反代一样：收你的请求，转发给真正的模型厂商，再把结果返给你。

为什么要用它？原因很实际：

  • 方便：一个 key 调遍所有模型，不用每家注册
  • 便宜：有些渠道能拿到折扣额度
  • 绕开限制：某些地区或某些支付方式用不了官方服务

代价是什么？你的请求内容经过了第三方的手。 所以中转适合跑不敏感的任务，真正机密的东西不要往里塞。

反代和中转的关系：反代是自己搭的桥，中转是别人搭好收过路费的桥。

四、逆向：从结果倒推原理

前面三个词都是"用 AI"，逆向是"拆 AI 和拆软件"——从成品倒推它是怎么做出来的。

它本来是软件安全领域的老手艺：把编译好的程序拆回汇编、看懂逻辑、找出原理。现在 AI 圈借用了这个词，出现两种新用法：

  • AI 辅助逆向：让 AI 读反汇编结果、解释一段汇编在干什么、写分析脚本。代表作是 GitHub 上星标 46 万的 REA——它本身不是逆向工具，是逆向工具的外脑
  • 逆向 AI 本身：通过大量输入输出，倒推一个模型的系统提示词、训练偏好、护栏规则。这其实是破甲的"温和版"——不硬闯，靠观察推断

那批真正因逆向而火的项目也值得知道：Wine 逆向 Windows API 让 Linux 能跑 Windows 程序，ReactOS 逆向重实现一个开源 Windows，Proton 让 Steam Deck 能玩 Windows 游戏。它们都是重实现功能，不是照抄代码——这是合法的边界。

五、无头与编排：把 AI 藏到幕后

前面几个词都在讲"怎么让 AI 听我的"。这一节反过来：让 AI 消失，只留下它在替你干活。

QQ 机器人圈子里有两个词很典型：NapCat 和 AstrBot。它们分工清楚——

  • NapCat 是"管道"：它把 QQ 客户端的收发消息能力抽出来，翻译成通用协议。它没有界面，安静跑在后台，只负责数据的进和出。这叫无头（headless）——不要脸，只要能力
  • AstrBot 是"大脑"：它接到消息后判断意图、调用大模型、挂插件、管上下文，再把回复丢回管道。这叫编排（orchestration）——AI 不直接面对人，而是被调度

这和第二节的反代是同一个思想的另一层：反代翻译的是 API 协议，NapCat 翻译的是平台消息。一个让工具连上模型，一个让聊天框连上工具。

六、Vibe Coding：AI 不写文章了，它写代码

最近在视频圈爆火的一个词。Vibe Coding 直译是"氛围编程"——你不管代码怎么写，只管说要什么效果，AI 直接把可运行的代码吐出来。

最典型的应用是那种讲知识的动画视频（网友叫"开智的小曲"）。很多人以为是 Sora、可灵这类视频模型生成的，其实不是：

  • 你给 AI 一段科普文案，它直接写出前端网页代码——分镜、排版、配色、动画全在里面
  • 再用 Remotion 这类工具，把网页逐帧渲染成视频。本质上，视频是"代码跑出来的"，不是"模型画出来的"
  • 配上 TTS 语音和字幕，时间轴由代码对齐

这条路的生产力高得离谱：改一句话重新渲染就行，不用重拍、不用剪辑。

无头 + 编排把 AI 藏起来，你只看到结果；Vibe Coding 把 AI 推到台前，代码就是它的作品。一个做减法，一个做加法。

七、为什么都和 AI 有关

你可能会问：这些词有的是 AI 时代的新词，逆向是个老手艺，为什么会被放在一起？

因为它们本质上都在回答同一个问题：当能力和资源都被别人掌控时，使用者怎么争取主动权。

  • 破甲：模型说"不行"，你想让它说"可以"——争取能力的主动权
  • 反代 / 中转：模型只认自己的协议和账号，你想换个用法——争取访问方式的主动权
  • 逆向：只给你一个成品，你想知道它怎么做的——争取认知的主动权
  • 无头 / 编排：不想让 AI 站在台前，只想让它安静干活——争取控制权
  • Vibe Coding：不想手写代码，只想说要什么——争取生产力

这也是为什么这些词会在 AI 时代集中爆发：模型越来越强、越来越集中、越来越黑盒，于是"怎么绕过去、怎么看懂它、怎么为我所用"就成了一整套新的民间技术。

知道这些词不是为了炫技，是为了出问题时知道该搜什么。每一个词背后，都有一整片世界。
