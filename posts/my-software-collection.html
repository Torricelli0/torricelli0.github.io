我的软件与收藏清单
从开发环境到日常效率

把我电脑上真正在用的软件和收藏夹里反复打开的网站翻出来，按「成对对比」讲——功能相近的放一起，说清楚我为什么选这个、不选那个。

工具效率macOS收藏

写在前面

软件推荐最常见的写法是逐个列功能，读完你知道它「支持什么」，还是不知道自己「需不需要」。这篇换个结构——功能相近的软件成对摆在一起，讲清楚选择逻辑。

一、AI 工具：成对比

DeepSeek Harness & Trae CN — 两种 AI 工作方式

痛点：AI 编程工具有两类完全不同的用法，选错方向会浪费很多时间。

怎么解决：DSH（DeepSeek 官方 Agent Harness）是"Everything is a Plugin"的 Agent 框架——所有能力都是插件，我用它做 skill 开发、插件市场和长任务编排。Trae CN 是字节的 AI IDE，更接近 Cursor 那种"写代码时的伴随式补全"。

对比：

  • DSH：管「让 AI 自己干活」——插件、skill、MCP、多 agent 协作。适合搭工作流。
  • Trae：管「我写代码时 AI 帮我」——补全、chat、代码生成。适合日常编码。

两个不冲突：Trae 是编辑器，DSH 是 Agent 运行时。

Cursor — 把 AI 装进编辑器骨架

痛点：用网页版 ChatGPT 写代码要来回复制——描述需求、复制代码、贴回编辑器、报错再复制出去。

怎么解决：AI 能看到当前文件、整个项目目录、报错信息。选中代码按 Cmd+K 说「改成分页查询」，它直接改在原位。

对比：和 Trae 是同类（都是 AI IDE）。我两个都装了，Cursor 的上下文理解更成熟，Trae 国内访问更稳。具体用哪个看当时网络和任务。

CC Switch & Magpie — 两个"网关/切换器"，别搞混

痛点：Claude Code 和 Codex 这类工具默认只认官方端点。想换模型、换供应商、或走本地网关时，需要一个中间层。

怎么解决：这两个都是"改配置指向本地网关"的工具，但管的对象不同：

  • CC Switch：主要管 Claude Code 的供应商切换。它会改写 Claude 的配置，让请求转发到 DeepSeek/WorkBuddy 等。端口 15721，配置在 ~/.cc-switch/。
  • Magpie：管所有 agent 的模型选择（Claude / Codex / DSH），本地网关端口 3425。它还带模型目录、profiles 快照、备份等功能。

对比与坑：CC Switch 更专注 Claude，Magpie 更全面。但两者都会改写 agent 配置——如果同时用，很容易互相覆盖。我之前就踩过：Codex 的 openai_base_url 被 Magpie 指向了本地 3425，导致想用官方模型时用不了。结论：同一个 agent 只让一个工具接管。

二、写作与知识：Obsidian & Typora

Obsidian — 让笔记变成能被 AI 直接读的知识库

痛点：笔记散在印象笔记、飞书文档、微信收藏里。想找三个月前记的概念靠关键词翻半天；想让 AI 整理还得一篇篇复制。

怎么解决：所有笔记就是本地文件夹里的 .md 文件。AI 能直接读这个文件夹——你说「把我关于 RAG 的笔记归纳成一篇」，它扫目录就能做。双链和图谱让概念自动连成网。

对比：Notion 笔记在云端，AI 要读得走 API 还有额度；印象笔记导出格式混乱。Obsidian 的本地文件夹是任何 AI 工具都能直接访问的格式——这是它在 AI 时代重新变热的原因。我现在有 382 篇笔记。

Typora — 写长文时不被预览窗分心

痛点：普通编辑器写 Markdown，左边源码右边预览，一半屏幕浪费，眼睛来回跳。

怎么解决：边写边渲染，所见即所得。敲 ## 标题 立刻变成标题样式。

对比：Obsidian 也能写，但它偏「知识体系」，文件多了界面复杂。Typora 只做一件事：专注写这一篇。我用 Obsidian 管知识库，Typora 写要发出去的文章。

三、界面与输入：小而美的工具

Hidden Bar — 让菜单栏清爽

痛点：Mac 顶部菜单栏装多了图标，挤成一团，还占屏幕。

怎么解决：在菜单栏插一条分隔线，右边的图标点一下折叠、再点展开。

对比：系统自带没有这功能；其它菜单栏管理工具要么收费要么太重。Hidden Bar 免费、极简、只干这一件事。

青简输入法 — 打字时顺便显示英文

痛点：写中文时想不起某个词的英文怎么说，得停下来切到翻译软件查。

怎么解决：它最特别的地方是打字时会顺带显示对应的英文单词——你在输入中文的同时，英文就摆在候选栏里，不用中断思路去查。对写技术文章、记英文术语很顺手。

缺点：因为多了一层翻译显示，打字会变慢一点，也更容易选错候选。适合写作场景，不适合追求极致输入速度的时候。

小提示：输入法装在 ~/Library/Input Sources/ 而不是 /Applications，所以在应用列表里找不到它。官网 qingjian.app 下载。

四、下载与网络

Gopeed — 多线程下载器，配合油猴脚本

痛点：别人分享 20GB 网盘资源，转存提示空间不足；或浏览器下载大文件经常断。

怎么解决：先纠正一个常见误解——Gopeed 本身不能解析网盘分享链接。真实流程两步：先用油猴脚本（「网盘直链下载助手」或「LinkSwift」，装一个就行）从分享页提取直链，再把直链交给 Gopeed 下载。Gopeed 只负责拿到 URL 后高速稳定地下载。

对比：浏览器下载大文件容易断、不支持多线程续传；IDM 收费且 BT/磁力支持弱。Gopeed 同时处理 HTTP、BT、磁力、ed2k，开源免费。但网盘场景必须配合油猴脚本，单靠它做不到。

Clash Verge Rev — 代理客户端

痛点：需要按规则分流（国内直连、国外走代理），手动改系统代理太麻烦。

怎么解决：读配置文件里的规则，自动判断每个域名走哪条线。

对比：Clash for Windows 已停更；这个是基于 Tauri 的续作，Mac/Win/Linux 通用。这里只提软件本身，具体配置各家方案不同。

五、浏览器扩展

沉浸式翻译 — 看英文文档不切标签页

痛点：读英文技术文档时，遇到不认识的段落要复制到翻译网站，翻完再回来，节奏全断。

怎么解决：把译文插在原文下方，不替换原文。你能对照着看，术语不会因为翻译变形而看不懂。支持 PDF、字幕、电子书。

对比：浏览器自带翻译会整页替换，术语经常错得离谱，而且不支持 PDF 和字幕。

uBlock Origin Lite — 页面加载快一点

痛点：很多网站广告和追踪脚本比正文还大，页面卡、流量白耗。

怎么解决：在页面加载前拦截请求，不下载那些脚本。

对比：Manifest V3 版本，比原版轻。同类 AdBlock Plus 默认放行「可接受广告」，这个规则更严格。

Bitwarden — 密码不该记在脑子里

痛点：几十个网站用不同密码记不住，用同一个又不安全。

怎么解决：浏览器扩展自动填充，主密码只记一个。开源自托管，数据可以自己存。

对比：1Password 体验更好但收费；Chrome 自带密码管理绑定浏览器，换浏览器就没了。Bitwarden 免费版功能完整。

篡改猴（Tampermonkey）— 给网页打补丁

痛点：某些网站功能不全或不好用（GitHub 全英文、B站不能批量下载、网盘分享页不显示直链），但你改不了它的代码。

怎么解决：装用户脚本，在页面加载后修改 DOM。我装的是：网盘直链下载助手 / LinkSwift（二选一，给 Gopeed 提供直链）、GitHub 汉化、B 站下载。

对比：Violentmonkey 是同类替代，功能差不多。选它只是因为用户基数大，脚本兼容性好。

七、一点原则

写这份清单的过程本身比清单有用。我一边写一边问自己「为什么留着它」，答不上来的就删了。

工具的多少不代表能力。能说清楚「为什么留着它」，并且确认它真的存在，才算真的在用。
