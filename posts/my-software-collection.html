我的软件与收藏清单
从开发环境到摸鱼工具

把我电脑上 78 个软件和浏览器里 97 个收藏翻出来，只留那些真正解决问题的。每款都回答三件事——它会遇到什么麻烦、怎么解决、为什么不用别的。

工具效率macOS收藏

写在前面

市面上的「软件推荐」大多有个毛病：把官网的功能列表抄一遍，读完你知道了它「支持什么」，但不知道自己「需不需要」。

所以这篇换个写法。每款软件我只回答三个问题：

  • 什么情况下你会需要它（痛点）
  • 它怎么解决的（机制，一句）
  • 为什么不用同类（差异点）

能说清楚这三条的留下，说不清的删了——这也是我电脑上现在只剩这些的原因。

一、桌面软件

Obsidian — 让笔记变成能被 AI 直接读的知识库

痛点：笔记散在印象笔记、飞书文档、微信收藏里。想找三个月前记的一个概念，靠关键词翻半天；想让 AI 帮你整理，还得一篇篇复制粘贴。

怎么解决：所有笔记就是本地文件夹里的 .md 文件。AI 能直接读这个文件夹——你说「把我关于 RAG 的笔记归纳成一篇」，它扫目录就能做。双链和图谱让「RAG」「向量检索」「embedding」这些概念自动连成网，点一个跳出一串相关的。

为什么是它：Notion 的笔记在云端，AI 要读得走 API 还有额度；印象笔记导出格式混乱。Obsidian 的本地文件夹是任何 AI 工具都能直接访问的格式——这是它在 AI 时代重新变热的原因。我现在有 382 篇笔记在里面。

Typora — 写长文时不被预览窗分心

痛点：用普通编辑器写 Markdown，左边源码右边预览，一半屏幕浪费了，而且眼睛要在两边来回跳。

怎么解决：边写边渲染，所见即所得。你敲 ## 标题，它立刻变成标题样式，但光标还在文本流里。

为什么是它：Obsidian 也能写，但它更偏「知识体系」——文件多了以后界面复杂。Typora 只做一件事：专注写这一篇。我拿 Obsidian 管知识库，拿 Typora 写要发出去的文章。

iTerm2 — 让终端变成能干活的地方

痛点：macOS 自带 Terminal 只有一个窗口。想同时看日志、跑测试、改配置，得开三个窗口再手动摆位置；输出太长往上滚就找不到了。

怎么解决：分屏（一屏切四块）、Cmd+F 搜历史输出、热键唤出半透明窗口（写代码时随时瞄日志）。配置存成文件，换电脑复制过去就是原样。

为什么是它：系统 Terminal 不支持分屏和搜索；Warp 更现代但要登录账号。iTerm2 免费、无账号、配置可迁移。

Cursor — 把 AI 装进编辑器骨架里

痛点：用 ChatGPT 写代码要来回复制——describe 需求、复制代码、贴回编辑器、报错再复制出去。

怎么解决：AI 能看到你当前文件、整个项目目录、报错信息。选中一段代码按 Cmd+K 说「改成分页查询」，它直接改在原位，不用复制。

为什么是它：VS Code 装 Copilot 插件也能补全，但「理解整个项目上下文再改」这件事不如 Cursor 原生做得顺。缺点是它基于 VS Code 分支，插件生态偶尔跟不上。

Sublime Text — 打开大文件不卡

痛点：几百兆的日志、CSV、JSON，用 VS Code 或 Cursor 打开会卡死，风扇狂转。

怎么解决：原生代码写的，内存映射加载，几十兆文件秒开。

为什么是它：不用它写项目，也不装插件，纯粹当「看一眼大文件」的工具。这个场景替代品很少。

GitHub Desktop — 复杂 Git 操作时少动脑

痛点：命令行提交当然快，但看到 diff 要改哪几行、只想提交一部分文件、或者处理合并冲突时，纯文本界面容易出错。

怎么解决：图形化显示每个文件的改动行，能勾选只提交某个文件、甚至某个 hunk。

为什么是它：我两个都用——日常 commit 用命令行快，复杂操作开它。它不是命令行替代品，是互补。

Docker Desktop — 不在本机装一堆数据库

痛点：想跑一下别人的项目，README 说要 MySQL 5.7 + Redis 6 + Python 3.9。在你已经装了 MySQL 8 和 Python 3.12 的机器上，这是灾难。

怎么解决：每个项目一个容器，依赖全打包在里面。跑起来 docker compose up，用完 down，本机环境干净如初。

为什么是它：Colima 更轻但 GUI 缺失、排查问题要命令行；OrbStack 更快但要付费。Docker Desktop 免费版够用，图形界面看容器状态直观。

Raycast — Spotlight 的加强版

痛点：系统 Spotlight 只能搜文件和应用。想查剪贴板历史、算个数、看时区、直接开 GitHub 仓库，都得切到浏览器或别的 App。

怎么解决：一个快捷键唤出，能装扩展。我常用的是：剪贴板历史（找回十分钟前复制的东西）、窗口管理（快捷键切左右分屏）、快速计算。

为什么是它：Alfred 是老牌但免费版功能受限；系统 Spotlight 不能装扩展。Raycast 免费版已经覆盖 90% 的日常需求。

二、下载与网络

Gopeed — 绕过网盘空间限制，直接下到本地

痛点：别人分享了一个 20GB 的网盘资源，你点「转存」提示「空间不足」。想腾空间得删东西，或者开会员扩容。

怎么解决：不经过你的网盘账号。拿到分享链接后，Gopeed 直接向源服务器请求文件，下载到你电脑硬盘——网盘只是个「链接中转站」，不占你的配额。

为什么是它：浏览器下载大文件容易断、不支持多线程续传；IDM 收费且对 BT/磁力支持弱。Gopeed 一个软件同时处理 HTTP、BT、磁力，跨平台，开源免费，Go 写的内存占用低。

Clash Verge Rev — 代理客户端

痛点：需要按规则分流（国内直连、国外走代理），手动改系统代理太麻烦。

怎么解决：读配置文件里的规则，自动判断每个域名走哪条线。

为什么是它：Clash for Windows 已停更；这个是基于 Tauri 重写的续作，Mac/Win/Linux 通用，界面更现代。具体配置各家方案不同，自己解决。

三、浏览器扩展

沉浸式翻译 — 看英文文档不切标签页

痛点：读英文技术文档时，遇到不认识的段落要复制到翻译网站，翻完再回来，节奏全断。

怎么解决：把译文插在原文下方，不替换原文。你能对照着看，术语不会因为翻译变形而看不懂。支持 PDF、字幕、电子书。

为什么是它：浏览器自带翻译会整页替换，术语翻译经常错得离谱。Chrome 自带翻译还不支持 PDF 和字幕。

uBlock Origin Lite — 页面加载快一点

痛点：很多网站广告和追踪脚本比正文还大，页面卡、流量白耗。

怎么解决：在页面加载前拦截请求，不下载那些脚本。

为什么是它：Manifest V3 版本，比原版轻，对页面性能影响小。同类 AdBlock Plus 默认放行「可接受广告」，这个规则更严格。

Bitwarden — 密码不该记在脑子里

痛点：几十个网站用不同密码记不住，用同一个又不安全。

怎么解决：浏览器扩展自动填充，主密码只记一个。开源自托管，数据可以自己存。

为什么是它：1Password 体验更好但收费；Chrome 自带密码管理绑定浏览器，换浏览器就没了。Bitwarden 免费版功能完整，跨浏览器跨设备。

篡改猴（Tampermonkey）— 给网页打补丁

痛点：某些网站功能不全或不好用（GitHub 全英文界面、B 站不能批量下载），但你没法改它的代码。

怎么解决：装用户脚本，让脚本在页面加载后修改 DOM。我装了 GitHub 汉化、B 站下载、网盘直链几个。

为什么是它：Violentmonkey 是同类替代，功能差不多。选它只是因为用户基数大，脚本兼容性好。

四、收藏的网站

浏览器里 97 个书签，大部分是求职和课程相关的临时链接。真正反复打开的是这几个：

查概念 / 八股

  • 小林 coding — 图解计算机网络、操作系统、MySQL。面试前复习用，比啃教材快
  • CodeTop — 按公司分类的高频面试题。刷题前先看这里定优先级，避免盲目刷
  • OI Wiki — 算法竞赛知识库，讲得比大多数博客系统

找资源 / 工具

  • iLovePDF — PDF 合并、压缩、转格式。论文排版时高频用
  • wallhaven — 高质量壁纸站，按标签筛。比搜索引擎找图靠谱
  • remove.bg — 一键抠背景，做演示图时省事
  • Kaggle — 数据集和 notebook。学机器学习时找练手数据

看论文 / 长文

  • arXiv — 预印本，看最新研究先来这里
  • lintsinghua.github.io — 有人写的 Claude Code 架构深度剖析，值得读
  • Hellogithub — 定期推荐有趣的开源项目

五、一点原则

写这份清单的过程本身比清单有用。我一边写一边问自己「为什么留着它」，答不上来的就删了——这轮删掉了 6 个。

现在留下的每个都能说出：什么场景下我会打开它。说不出这个的，要么是我忘了它存在，要么它本来就不该装。

工具的多少不代表能力。能说清楚「为什么留着它」，才算真的在用。
