我的软件与收藏清单
从开发环境到摸鱼工具

把我 dotfiles 里的 78 个软件和浏览器里 69 个收藏翻出来，挑那些真正在用的。每个只说清楚一件事：它解决什么问题。

工具效率macOS收藏

写在前面

这份清单不是「十大必装软件」那种。它是我自己电脑上真实在跑的，附上为什么留着它。有些你可能用不上，但至少能知道有这么个东西存在。

原则有三条：只装解决具体问题的、能免费的不用付费的、装完三个月没打开就删。

桌面软件：开发与效率

1. iTerm2 — 终端

macOS 自带 Terminal 够用，但 iTerm2 的分屏、搜索、热键唤出窗口是回不去的东西。配置全在 ~/.config/iterm2，跟着 dotfiles 走。

2. Cursor — 编辑器

VS Code 的分支，把 AI 补全和 Chat 做进了编辑器骨架里。我主要用它写代码和改配置。插件和设置走 Settings Sync，换机器登录账户就回来了。

3. Sublime Text — 备用编辑器

打开几十兆的日志、CSV、JSON 时比任何 Electron 编辑器都快。不用它写项目，只用来「看一眼大文件」。

4. GitHub Desktop — 图形化 Git

命令行当然更快，但可视化看 diff、挑文件提交、处理冲突时省脑子。我两个都用：日常 commit 用命令行，复杂操作开它。

5. Docker Desktop — 容器

跑数据库、跑别人的项目、复现环境问题。有了它就不用在本机装一堆 MySQL、Redis。

6. Raycast（可选替代 Spotlight）

比 Spotlight 强的地方是它能装扩展：剪贴板历史、窗口管理、快速计算、直接搜 GitHub。免费版已经够用。

7. Hidden Bar — 菜单栏折叠

Mac 顶部图标越装越多，它会插一条分隔线，把右边的图标折叠起来。点一下展开，再点隐藏。视觉上干净很多。

下载与网络

8. Gopeed — 下载器

支持 HTTP、BitTorrent、磁力链接。我主要用它下载一些公开的镜像文件和大体积素材。Go 写的，跨平台，内存占用比同类低。

9. Clash Verge Rev — 代理客户端

开源的 Clash 图形界面，配置从订阅导入。这里只提软件本身——具体配置和订阅各家不同，自己解决。

笔记与知识管理

10. Obsidian — 本地笔记库

所有笔记存成本地 markdown 文件，不上传任何人服务器。双链、图谱、插件生态是它的强项。我目前有 382 篇笔记在里面。

11. Typora — 即时渲染 Markdown

写长文时用。没有预览窗，边写边渲染，所见即所得。比 Obsidian 更专注写作本身。

这两个搭配用：Obsidian 管知识体系，Typora 管单篇写作。

浏览器扩展（从 12 个里挑 6 个）

12. uBlock Origin Lite — 广告拦截

Manifest V3 版本，比原版轻。拦广告和追踪器，网页加载更快。

13. 沉浸式翻译 — 双语对照

看英文文档时，它把译文插在原文下方，不替换原文。技术文档、论文、GitHub README 都靠它。

14. Bitwarden — 密码管理

开源自托管选项，免费版够用。所有密码、API key、订阅链接都存这里。

15. 篡改猴（Tampermonkey）— 用户脚本

给网页打补丁的容器。我装了 GitHub 汉化、B 站下载、网盘直链这几个脚本。

16. 牛客网申助手 — 校招填表

自动填写招聘网站的表单。校招季省时间用的，非求职期可以关掉。

17. ChatGPT / Claude — AI 侧边栏

不用切标签页就能问 AI。两个都装是因为不同任务用不同模型。

收藏的网站

技术类

  • 小林 coding — 图解计算机网络、操作系统、MySQL，复习八股的图文资料
  • CodeTop — 按公司分类的高频面试题，刷题前先看这里排优先级
  • 卡码笔记 — 程序员八股文整理，配合卡码网的题目用
  • 菜鸟教程 — 语法速查，不用翻官方文档那么长
  • 自学 SQL 网 — 交互式练 SQL，边写边看结果
  • 洛谷 / LeetCode — 刷题平台，按难度和标签筛题

工具类

  • iLovePDF — 合并、压缩、转格式，PDF 相关的杂活基本都能干
  • remove.bg — 一键抠背景，做演示图时用
  • Desmos — 在线图形计算器，画函数图像比手算直观
  • SuperText — 批量文本处理，去重、排序、格式转换
  • wallhaven — 高质量壁纸站，按标签筛
  • Kaggle — 数据集和 notebook，学机器学习时找练手数据

资料与文献

  • arXiv — 预印本论文，看最新研究先来这里
  • IEEE Xplore — 工程类正式发表论文
  • 中国知网 — 中文文献，写论文查引用
  • HelloGitHub — 定期推荐有趣的开源项目
  • 掘金 — 中文技术社区，实践类文章多

一点原则

装软件这件事，我慢慢形成了一个习惯：先想清楚要解决什么问题，再去找工具。反过来（看到推荐就装）的结果是硬盘塞满、菜单栏拥挤、每次重装系统都要重来一遍。

所以现在我会把每个软件的「为什么留着」写进 dotfiles。三个月没打开过的，删掉。留下来的每个都能说出用途。

工具的多少不代表能力，能说清楚为什么留着它才是。

完整的软件清单（78 个，含安装方式和 GitHub 地址）在 dotfiles 仓库 的 APPS-CATALOG.md。
